# V7 TODO：数据组成与监督来源

本文件记录下一轮训练的核心观点与待验证方案。V6 继续按已确定的流程执行；V7 的老师、配比和训练预算尚未冻结。

## 一、核心观点

1. **以老师自对弈为主，老师与其他模型的对战为辅。** 自对弈提供主要监督与完整胜负，交叉对局用于扩大局面分布、发现老师的弱点。
2. **老师是待验证的监督来源，不是真值。** 老师输棋不能证明它全盘判断都错，但也不能默认其搜索标签比获胜对手更好。
3. **保留少量有价值的对手判断。** 对手获胜时，可以考虑吸收其部分原始 policy/q，尤其是已有独立评测支持其棋力或互补性的模型。
4. **默认优先筛选，不做全量 reanalyze。** 对战已经付出了 MCTS 成本，应尽量利用当时保存的搜索结果，减少训练前的串行等待。
5. **数据不足时，优先考虑增加有多样性的自对弈局数。** 关注新增独立局面和可用监督，而不只是棋谱数量。
6. **V7 的老师需要重新探索后确定。** 不预设仍是 mix-v5-h3，也不预设融合模型一定优于单网络。

## 二、为什么调整 V6 的数据思路

V6-full 使用“多来源局面、统一 mix 老师重分析”的路线，便于控制监督来源，但有两个局限：

- 同一个老师、相同搜索预算重新分析，不一定能修正老师已经暴露的盲区，也可能覆盖其他模型的有效判断。
- 5,000 个局面各搜索 5 秒，约需 6.9 worker-hours；即使并行，仍明显延长从评测到训练的等待时间。

因此 V7 优先研究：**复用已有搜索标签，通过来源识别、筛选和少量混合保留互补性，而不是把所有标签重新统一成一个模型的判断。**

## 三、数据组成：先从简单比例开始

### 建议的首轮训练抽样比例

| 来源 | 初始占比 | 用途 |
|---|---:|---|
| 冻结老师自对弈 | 85% | 主体棋力、policy/value 和战术监督 |
| 老师与其他模型交手中的老师步骤 | 10% | 学习不同风格施加的局面分布，包含老师胜局与负局 |
| 经筛选的获胜对手步骤 | 5% | 少量吸收对手的有效判断与互补策略 |

以上是**训练样本抽样比例，不是对局盘数比例**。对局采集也以老师自对弈占大多数、交叉对局占小多数为方向，但应根据每类实际产出的独立样本调整。

两种可选起点：

- **保守对照：90% 自对弈 + 10% 交叉对局老师步骤。** 不引入其他模型的标签。
- **互补方案：85% 自对弈 + 10% 交叉对局老师步骤 + 5% 获胜对手步骤。** 作为优先尝试方案，检验对手监督的净收益。

两者使用相同热启动、更新预算和评估集。若合格的对手样本不足，不为凑比例反复过采样极少数棋谱；先降低其占比或补充对局。

旧数据回放不自动继承 V6 的 10% 配额。先检查 V7 是否出现遗忘，再决定是否从主体比例中分出少量回放。

## 四、如何使用“获胜对手的判断”

### 1. 胜负是筛选线索，不是逐步正确性的证明

- 不采用“赢家全盘都对、输家全盘都错”的规则。
- 不剔除老师的全部负局；这些棋谱正是弱点暴露的重要来源。
- 获胜对手的局面应标为“胜局来源”，而不是“已验证的正确动作”。
- 优先采用独立评测中表现较强、或确实暴露了老师特定弱点的对手，避免仅凭偶然胜局决定监督来源。
- 平衡对手、颜色和棋谱贡献；不要让某个对手的执黑胜局、超长棋谱或重复开局占据大部分新增监督。

### 2. 首选样本层面的混合

首轮的“融合判断”是：**在小比例样本上保留原行棋模型的 π/q，并记录来源**，不是直接融合网络权重，也不是把老师与对手的标签无差别平均。

- 不同局面的 policy/q 不能直接平均。
- 同一个 D4 等价局面若有不同模型标签，先保留来源，按模型/搜索记录处理；不要沿用单老师 loader 的无条件合并。
- 如果以后探索同局面输出融合，必须对齐棋盘坐标、行棋方视角和搜索条件，并另行验证收益。

### 3. policy 和 value 分开考虑

- 老师自对弈可继续以 `0.25z + 0.75q` 为 value 起点，最终配方待 V7 验证。
- 交叉对局 quiet 步首轮优先使用标签来源模型自己的 π/q，value 以 q 为主。
- 不能因为模型赢了，就把它所有局面的 value 标成“必胜”；最终 z 受到双方后续决策影响。
- 不同模型的 q 可能有不同校准误差，按来源单独评估，不用 q 的绝对大小直接决定谁更可信。
- tactical 无 q 的步骤首轮仍主要从老师自对弈获得；不把获胜对手的全部战术步骤自动变成强监督。

## 五、优先仅筛选，减少 reanalyze

### 默认路线

1. 对战时保存搜索访问分布、q、战术标记、模型来源和搜索预算。
2. 按棋谱/局面去重、标签有效性、来源、颜色与胜负分层筛选。
3. 将合格的原始标签直接加入训练，不要求先全部重新搜索。
4. 数据不足时追加自对弈或有针对性的交叉对局，继续利用对战本身产出的标签。

搜索访问数用于识别低质量或不可比记录，不机械按访问数加权；不同模型的推理成本不同，访问更多不等于标签一定更好。

### reanalyze 留作可选的局部工具

只有明确的问题值得付出额外成本时再考虑，例如：

- 强模型在同一局面有关键分歧；
- 某类失败反复出现，需要更充分的搜索判断；
- 原记录缺失必要标签，且该局面确有保留价值。

不把“再跑一次相同老师、相同预算”视为自动纠错，也不让全量重分析成为每轮训练的固定前置步骤。

增加自对弈局数并不必然比重分析省算力：完整对局会搜索很多步。应比较**单位墙钟时间新增的有效独立样本**，以及是否避免重复搜索和长时间等待，而不是只比较局数与局面数。

## 六、V7 老师探索

- 等 V6-full 完成训练和对战后，将 V6-base、V6-full、现有 mix 等作为候选。
- 按固定开局换先、统一实际落子预算和并发条件比较；既看综合对手表现，也看相互交手及分颜色结果。
- 若探索新的融合老师，同时检查棋力与搜索吞吐，不默认更复杂的融合更好。
- 先选择主体老师，再决定哪些其他模型值得作为对手和少量监督来源。
- 采集前冻结老师配方、权重和搜索配置；不同版本的数据明确区分。

## 七、先手优势与“白胜时不学黑”的候选启发

**判断：适合作为筛选和分层评估的启发，不宜直接变成“白胜棋谱中黑方样本全部删除”的规则。**

- 可以使用“黑方具有先手优势”作为工作先验；不把所有规则、开局和实际局面都视为黑方必胜。即使某个初始局面在最优策略下黑胜，也不代表经过实际落子后的每个黑方局面都仍然可胜。
- 白胜值得重点分析：它可能暴露黑方失误，也可能来自强制/采样开局、搜索预算不足等因素。但整盘结果不能定位是哪一步出错，更不能说明黑方所有步骤都错。
- 当前 policy 标签是 MCTS 访问分布，不是实际落子的 one-hot。尤其前几步有随机采样，实际走出的败招可能并非搜索分布最偏好的动作；不能仅凭输棋否定整条 π。
- policy 与 value 分开处理。黑方负局中的部分 policy 可能不值得模仿，但其失败状态对学习负价值仍有用；全部删除容易造成胜者偏差，令黑方 value 过于乐观。
- 黑胜也不能自动视为高质量示范；黑方可能犯错后仍因白方未抓住机会而获胜。

可选实验，暂不设为默认：

1. **优先方案：按颜色与胜负分层，不删黑方负局。** 在少量对手监督中增加关注白方获胜样本，同时保留来源和质量筛选；单独报告黑/白、胜/负的指标。
2. **对照方案：只降低黑方负局的 policy 权重。** 不自动删除对应的 value 样本，也不把对手获胜自动变成其全部 q 都可信。与无此规则的方案同预算比较，检查执白收益及黑方 value 校准。
3. 若以后有可信的关键失误定位，再针对失误前局面的 policy 做筛选；单靠相邻回合 q 下降不够，需对齐行棋方视角，并考虑模型来源不同、搜索噪声等影响。

目标是利用先手优势帮助发现弱点，而不是形成“只学黑方胜局”的数据分布。

## 八、切分、训练与验收

- 沿用已有数据的训练/验证/测试归属；旧保留集不重新流入训练。
- 重复棋谱、同局面多来源标签及其派生版本按组管理，避免跨集合泄漏。
- 用于筛选和训练的交叉对局作为开发数据，最终棋力结论来自新的独立对局。
- 同预算比较“仅老师监督”和“少量对手监督”，首轮不同时改变网络容量、训练时长与大量损失参数。
- 分来源报告 policy、value、tactical 和公共未见局面指标；保留实际样本曝光量。
- 检查加入对手标签后，是否改善对应弱点，同时保持常规棋力和已经学到的中心首手偏好。
