## 历史 review 与完整路线（开局部分已被上述决定取代）

建议 v6 继续做同构蒸馏，从 A3 热启动；先筛选一个更强的融合老师，再用“老师自对弈 + 不同风格对手 + 专门的开局覆盖数据”训练。
这次最值得解决的不是网络容量，而是三个问题：
1. 找到比 A3 更可靠的搜索老师，不能简单沿用 v4 的 80% 启发式配比。

2. v6 必须处理的问题
P1：前两步的监督缺口是实质性的
实际 teacher-20260911 数据中：
- 黑棋首手：2,000 盘全部落在中心，全部 t=true，没有 q。
- 白棋首手：有 policy/q，但只见过“黑棋中心，白棋邻近八格”的分布。
因此：
- A1/A2 完全跳过黑棋首手。
- A3 在空棋盘上只学了低权重胜负 value，没有学首手 policy。
- 白棋首手虽然参与了训练，但没有覆盖非中心黑棋首手。
而且当前代码中，python/mcts.py:45–60 仍然是：
- 空棋盘只给中心候选；
- 单子棋盘只给相邻八格候选。
这意味着即使重新采集数据，也会继续复制开局盲区。
P1：混合数据不能直接按现在的 loader 全部等权训练
python/train/train_sqlite_v5.py:64–114 读取了双方模型名，但没有把它们保留为样本的标签来源；相同棋谱的 policy/q 会直接平均。
在单一老师自对弈中可以接受，但加入 A1、A2、启发式对局后：
同一个局面可能混入强老师与弱对手的搜索标签，模型无法区分谁更可靠。
v6 需要保留逐步的 行为模型、标签老师、搜索预算，对不同来源明确处理。
P1：最佳 checkpoint 只按 quiet loss 选择
python/train/train_sqlite_v5.py:296 使用：
score = val["quiet"]["loss"]
即便开启 tactical 训练，选模也完全不考虑 tactical 表现；开局更没有独立指标。
v6 应同时保留：
- 综合验证目标最好的 checkpoint；
- 最终 checkpoint；
再用小型实战筛选。综合验证目标应包含固定比例的 quiet、tactical 和 opening，不能由各子集的样本数量偶然决定权重。
P2：验证集“不同对局”不等于“不同局面”
v5 的 quiet 验证样本共 4,156 个，其中未见局面只有 814 个，约 *19.6%*。
现有脚本已经报告这一点，做得对；但总体验证指标仍主要反映熟悉局面。
v6 建议：
- 同一初始局面派生的多盘续局、重分析版本必须在同一集合；
- 保留未见局面指标；
- 加入独立的异常开局测试集；
- 所有候选使用相同的评估子集，避免 A3 因训练过 tactical 局面而改变“unseen”的比较对象。
P2：policy 的训练与实际使用范围不一致
现在训练 softmax 覆盖全部 225 格，推理才屏蔽已占用位置。
v6 可以在训练和评估时统一屏蔽已占用位置，把概率学习集中在合法落点上。
这里不建议按“老师访问过的位置”做 mask，否则未探索动作会被误当成不合法。
3. 还有两个会影响老师筛选的问题
融合实现有重复计算。
python/models/__init__.py:26–40 中，同一个模型若同时贡献 policy 和 value，会被调用两次。旧融合老师就存在这个情况。
v6 融合视图应在每次局面评估中：
每个底层模型只调用一次，然后分别组合 policy/value。
这是直接减少融合开销，不需要引入跨局面的缓存系统。
Elo 更新存在先后顺序偏差。
python/selfplay/elo.py:20–21 先更新黑方，再用更新后的黑方分数计算白方变化；标准做法是基于更新前的双方分数同时计算。
同模型自对弈也不应更新 Elo，但目前会给同一个模型累加双方记录。旧老师的 4,310 场包含大量这种数据。
因此，老师筛选应主要看新的、同条件直接交手矩阵，同时局部修正 Elo 更新逻辑。
三、第一步：要不要先做融合老师？
要做，但把它当成待验证的候选，不假设融合一定更强。
推荐的融合形式
第一轮固定 policy 来自 A3，只调 value：
\[
P=P_{A3}
\]
\[
V=(1-\lambda)V_{A3}+\lambda V_H
\]
其中 \(H\) 分别尝试：
- heuristic-v2
- heuristic-v3
建议先测：
\[
\lambda\in\{0.25,\ 0.5,\ 0.75\}
\]
加上纯 A3，第一轮共 7 个候选。
不要直接认定 heuristic-v3 单体更强，就一定更适合融合。 单体排名同时包含它自己的 policy、value、计算成本；这些因素与“只借用 value”的效果不同。
A1/A2 是否需要融合？
建议按优先级处理：
方式	建议
A3 policy + 启发式 value 混合	优先
A2 policy + 第一轮最佳 value 配方	值得做一个对照
A3/A2 的 policy 概率混合	第二轮可选
A1/A2/A3 多网络同时集成	暂不优先
直接平均 A1/A2/A3 权重	不建议作为首轮方案
A2 的 policy 指标略好，但不能据此认定实战更好；一次交叉组合实验足以判断。
如果测试 policy 混合，采用输出概率的凸组合：
\[
P=(1-\beta)P_{A3}+\beta P_{A2}
\]
先只试 \(\beta=0.25\) 或 \(0.5\)。它会增加一次网络推理，必须计算同时间预算下的净收益。
是否增加超参数？
建议增加，但只增加有明确作用的少数几个。
参数	作用	首轮建议
value 混合权重 (\lambda)	平衡神经网络与启发式	0.25 / 0.5 / 0.75
c_puct	调整探索与 value 的相对作用	配方筛出后试 0.8 / 1.2 / 1.8
policy 混合权重 (\beta)	利用 A2/A3 的互补性	第二轮再试
不建议同时调启发式几十个分值、阶段性动态权重和 policy 温度。那会迅速变成大规模搜索，而且容易对小型对战集过拟合。
老师筛选流程
1. 去除融合中的重复推理。
2. 统一开局规则、搜索计时边界和评测并发条件。
3. 用相同开局集合换先评测，先筛掉明显弱的配方。
4. 最佳两三个候选增加对局。
5. 对纯 A3、旧老师、A2、heuristic-v3 都有稳定表现后，冻结老师。
以 5 秒实际落子预算下的得分率为主要目标，同时记录访问次数和耗时。更复杂的融合若导致搜索显著变浅，不值得作为在线最强模型。
如果没有融合候选稳定超过 A3，就直接用 A3 做老师。
四、第二步：如何把前两步真正训练进去
这里需要同时改搜索、采样、标签、评测，仅修改训练 loss 不够。
1. 放开开局搜索空间
建议在前四个 ply，即黑白各前两次落子时，候选覆盖全部空位。
这样不仅能训练：
- 黑棋空盘第一手；
- 白棋面对任意黑棋首手的应对；
还可以训练：
- 黑棋面对偏远白棋首手的第二次落子；
- 白棋面对异常前两步组合的后续应对。
否则只训练前两个决策，漏洞可能只是被推迟到第三手。
开局分支数增加后，需要给开局标签更充分的搜索预算，并记录访问量；不能把低访问的搜索结果当成已充分验证的答案。
2. 建立独立的开局数据集
局面类型	如何采样	训练内容
空棋盘	老师充分搜索、多次汇总	黑棋首手 policy/value
任意单黑子	覆盖所有 225 个落点	白棋首手 policy/value
黑白各一子	分层采样距离、中心/边/角位置	黑棋第二次落子
三子局面	从上述分支续局采样	白棋第二次落子
225 个单子位置在 D4 对称下只有 36 类。可以按 36 类生成高质量标签，再通过增强覆盖全部方向。
双子局面不需要全枚举，先选约 1,000–2,000 个不同局面，重点覆盖：
- 中心附近的正常开局；
- 近邻、间隔一格、中远距离应手；
- 边线、角落；
- 双方落在彼此很远的位置；
- 当前模型明显分歧的局面。
3. 强制多样性与老师监督必须分开
例如为覆盖角落开局，强制黑棋落在角落：
- 这是生成训练局面的动作；
- 不代表老师认为角落是最佳首手；
- 不能把强制角落动作写成空棋盘的 policy 标签。
正确做法是：
从这个单子局面开始，让老师搜索白棋的合理应对；需要空棋盘标签时，另行对空棋盘搜索。
同理，如果先搜索、再强制执行另一个动作，原根节点 q 与后续胜负 z 对应的行为不同，不应机械地混成同一目标。
4. 开局标签与训练比例
建议：
- 独立开局重分析数据：优先使用老师的 \(\pi,q\)。
- 有正常续局结果的局面：可以加入较低权重的 z。
- 空棋盘只有一个独立状态，汇总多次搜索即可，不必复制成几千个“独立样本”。
- 开局样本占训练抽样的 *约 10%*，保证被充分学习，但不过度挤占中盘训练。
这能降低开局分布缺口；是否真正改善异常开局，仍需单独对战验证。
五、第三步：v6 应采集什么样本
推荐路线：多来源局面，统一强老师监督
三个可选路线：
路线	优点	局限
纯最强老师自对弈	最简单，标签来源一致	容易重复，风格单一
老师自对弈 + 多对手 + 开局覆盖	质量与多样性兼顾	需要部分重分析
多老师全量集成、全量重分析	潜在标签更强	计算成本高，首轮不必要
推荐第二种。
首轮数据规模
先做约 3,000 盘新对局，外加开局局面集：
来源	建议数量
最佳老师自对弈	1,800 盘
老师 vs 多种对手	600 盘
指定开局后的老师续局	600 盘
独立开局重分析	约 1,000–2,000 个双子局面，加空盘及单子覆盖
这些是起始预算。完成前 300–500 盘后先看：
- 新增独立局面数；
- 完整棋谱重复率；
- 开局覆盖；
- 不同来源的标签质量和搜索访问数；
再决定是否按原比例跑满，而不是只追求盘数。
多对手如何选择
600 盘可先按六个对手各 100 盘、黑白各半：
- 纯 A3，若老师本身就是 A3，则换成另一个候选；
- A2；
- A1；
- 旧融合老师；
- heuristic-v3；
- nn4-policy-h2-value。
A1 的价值首先是产生不同局面，而不是一定要把它融合进老师。
是否长期保留某个对手，应看它带来了多少新局面、是否暴露老师的弱点，而不是名称不同就认为风格不同。
交叉对局标签怎么处理
每一步必须按当步来源区分：
- 老师行棋：使用老师搜索的 policy/q。
- 对手行棋：优先用冻结老师重分析该局面，产生 policy/q。
- 没有重分析的弱对手步骤：不要直接作为同权重 policy 蒸馏标签。
value 也要区分：
- 老师自对弈：可以继续用 0.25z + 0.75q。
- 对手步骤经老师重分析：主目标用老师 q。
- 弱对手后续失误导致的胜负 z，不能自动视为老师策略下的真实价值。
- tactical 无 q 的步骤：沿用较低权重 z 监督，单独统计效果。
旧数据是否保留
建议保留约 10% 的旧训练样本回放，抑制遗忘，并补充已有战术局面。
注意：
- 只使用原训练划分；
- 不把旧验证、测试集重新混进训练；
- 旧开局的强制中心标签不能作为新开局搜索质量的证据。
一个可用的初始抽样比例是：
样本来源	训练抽样占比
新老师自对弈	55%
跨风格对局与重分析	15%
异常开局续局	10%
独立开局局面集	10%
旧训练数据回放	10%
这些是样本抽样比例，与盘数比例分开控制。
六、v6 训练与验收方案
训练配置
第一轮继续：
- A3 热启动；
- H32/B4/V64 同构；
- AdamW，学习率从 1e-4 起；
- batch 128；
- 在线 D4 增强；
- tactical value 权重从 0.25 起；
- 按固定更新步数控制预算，同时记录各类样本实际曝光量。
将损失分成独立的几项，权重不再受 tactical 样本占比隐式改变：
\[
L =
L_{\text{quiet-policy}}
+L_{\text{quiet-value}}
+\lambda_tL_{\text{tactical-value}}
+\lambda_oL_{\text{opening}}
\]
各项先在对应样本内归一化；开局样本作为独立类别时，不重复计入 quiet 项。
首轮只做两个主候选
候选	用途
v6-base	A3 热启动，仅使用新老师的标准自对弈数据
v6-full	加入开局覆盖、跨风格重分析、旧数据回放
两者使用相同更新预算与评估集。这样能判断新数据方案有没有实质收益，而不是同时改变网络、损失和训练时长后无法解释结果。
验收分成两条线
常规棋力：
- 对 A3；
- 对冻结老师；
- 对旧融合老师；
- 对 heuristic-v3；
- 同开局换先、同时间预算。
开局鲁棒性：
- 所有单子位置；
- 保留的双子、三子异常开局；
- 边、角和远距离应手；
- 检查完整续局表现，而非仅判断第一步是否像老师。
空棋盘是唯一状态，不能靠把重复空盘分进测试集证明泛化；它应作为功能与策略质量检查。
最终建议的执行顺序
1. 局部修正评测与融合实现：Elo 同步更新、跳过自对弈计分、底层模型单次计算。
2. 统一开局搜索规则，建立固定的正常与异常开局评测集。
3. 筛选融合老师：A3 policy + H2/H3 value，先调混合权重，再调 c_puct。
4. 冻结老师，跑小批数据审计，确认独立局面和开局覆盖。
5. 采集约 3,000 盘及专项开局集，跨风格对手步骤按需重分析。
6. 从 A3 训练 v6-base / v6-full，再按常规棋力和开局鲁棒性共同选型。
核心选择是：把“最强模型”用于提供监督，把 A1/A2/启发式等模型用于扩大局面分布。 二者分开之后，v6 才能在吸收强老师能力的同时，减少 v5 在陌生开局和不同风格对局中的盲区。
